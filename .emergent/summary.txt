<analysis>**original_problem_statement:**
We will develop a website that will allow users to subscribe to price changes for products or services published on any website, for example, flight tickets, hotels, golf clubs, tools, clothes, shoes, subscriptions, etc. The user must enter a URL, the system will analyze the page and obtain information about what it offers (price, title, description, etc.) and will create that item in the user's account, who will be asked how they want to be notified when the price changes (email, WhatsApp, Telegram, etc.). The system will allow the user to create several items to track and will check the URL of each item every 12 hours to see if the item has changed its price. If it has changed, it will notify the user according to the option they selected.

PRODUCT REQUIREMENTS:
- User can submit a URL to track a product.
- The system scrapes the product's title, price, description, and image.
- Scraping should work in two ways (user's choice): basic scraping and AI-powered extraction.
- Users can choose to be notified via email, WhatsApp, Telegram, or SMS for each tracked item.
- Notifications are sent via a user-provided webhook endpoint ().
- Authentication should use Emergent-managed Google Auth.
- The design should be sober, elegant, and support system preference for light/dark themes.
- Price parsing must handle various currency formats (e.g., CLP with dots for thousands, USD with commas).
- User can configure their notification contact details (email, phone, etc.) in their account settings.
- The system must handle scraping-protected sites.
- If a URL cannot be scraped during the preview, the item should not be added. Instead, a message should be shown to the user stating that the site is not yet supported, and the team will be notified to enable it.
